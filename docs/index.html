Implement-AwareGuidance Simulator

Agricultural autosteer, measured twice

The tractor is on the line.
The implement is not.

Coverage quality depends on where the working edge of the implement sits, not on where the tractor sits. This simulator runs both at once, on real field terrain read from USGS elevation data.

Stanley improves the tractor figure by 34 percent and the implement figure by 14. Across the tuning sweep the two optimal lookahead gains diverge in every configuration tested, though not in the direction the project first assumed.

How it is built

Written by hand

Kinematic bicycle model, RK4 integrator, pure pursuit and Stanley, one-trailer hitch kinematics. No simulation framework, so the behaviour is defensible line by line. Checked against closed forms wherever one exists.

Every number has a source

Eighteen tractors and twenty one implements. Each physical value carries a citation or is flagged as an assumption with its reasoning. A value with neither cannot be loaded.

Real ground

Give it a location and it reads the field's actual slope from USGS elevation at one metre resolution and runs on that, so the disturbance changes under the machine as it drives.

Simulation output from a kinematic model. Not measurements from a real machine, and not validated against field trials. Several inputs are stated assumptions rather than published specifications.
