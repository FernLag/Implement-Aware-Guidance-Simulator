Privacy

This page describes what this deployment actually does with data, written against the running configuration rather than as boilerplate.

Cookies

{% if settings.sets_cookies %}

Analytics is switched on for this deployment. Before anything is stored you are asked to choose yes or no, and the choice is remembered in your browser. Declining leaves the simulator working exactly as it does when you accept.

{% else %}

Analytics is switched off for this deployment, and no analytics or advertising cookie is set. There is no consent banner because there is nothing to consent to.

{% endif %}

There is no session cookie either. The site has no forms and no accounts, so there is nothing to keep track of between one page and the next. You can confirm this in your browser's developer tools: the storage panel for this site is empty.

The simulator

Running a pass sends your chosen settings to the server, which computes the result and returns it. Nothing about a simulation run is stored. The settings are numbers describing a machine and a field condition and are not linked to you.

Server logs and rate limiting

Your network address is held in memory for a short period so that requests can be counted and abusive traffic slowed down. Entries that have been idle for fifteen minutes are discarded. Standard web server logs may record addresses and requested pages according to how the operator has configured the hosting.

Real field imagery and elevation

If you ask the simulator to read a real field, this server requests aerial imagery and elevation data from the U.S. Geological Survey on your behalf. Your browser does not contact them: it asks this site, and this site asks USGS. That means the coordinates you type reach USGS through this server, but your network address, your browser and any identifier of you do not.

The coordinates are not stored here. They are held only for the moment it takes to answer the request, along with a short lived cache of the imagery and elevation so that a repeated look at the same field does not ask USGS again.

Third parties

{% if settings.analytics_enabled and settings.analytics_script_url %}

This deployment loads an analytics script from {{ settings.analytics_script_url }}, but only after you choose yes.

{% else %}

No third party script, font, stylesheet or image is loaded into your browser. Every asset, including the aerial imagery described above, is served from this server, which is enforced by the content security policy the site sends with every page.

{% endif %}

Your rights

Where data protection law such as the UK GDPR or the EU GDPR applies, you have the right to ask what is held about you, to have it corrected or erased, and to complain to your supervisory authority. In practice this site holds nothing about you beyond the transient rate limiting entry described above. Requests go to the operator using the details in the footer.

{% if not settings.contact_configured %}

This deployment has no contact details configured, so there is currently no published route for such a request. That is a configuration gap, and it is stated here rather than concealed.

{% endif %}
