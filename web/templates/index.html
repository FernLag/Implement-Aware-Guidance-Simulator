What to look for

On flat ground both return to zero

Start the tractor three metres off the line with no slope. Tractor and implement both come back. The implement takes longer because a trailed implement lags the tractor through the correction.

On a slope neither returns

Add ten degrees of side slope. Pure pursuit settles at a fixed offset and stays there. The implement settles further out still, and the gap between the two does not close.

Stanley moves the tractor, not the implement

Switch controller and raise the cross-track gain. Tractor error falls sharply. Implement edge error falls by much less, because the crab angle that displaces the implement is set by the slope, not by the controller.
